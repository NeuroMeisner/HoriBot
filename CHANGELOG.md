## [1.3.1] - 2026-10-21
### Added



### Fixed
- Конфликт «terminated by other getUpdates request»: бот больше не может запуститься
  во второй копии на одной машине (mutex ОС), а при конфликте с копией на другой машине
  пишет понятный диагноз и корректно ждёт
- Flood control на SetMyCommands при частых перезапусках: команды устанавливаются
  только при фактическом изменении их набора
- UnicodeEncodeError ('charmap' codec) при выводе эмодзи в скрытом режиме запуска —
  потоки вывода принудительно переведены в UTF-8

### Changed
- start_bot.bat останавливает цикл автоперезапуска, если обнаружена другая копия бота
  (код выхода 42), вместо бесконечных перезапусков каждые 5 секунд


## [1.3.0] - 2026-10-20
### Added
- Автоматическая проверка обновлений с GitHub: при запуске бота и раз в сутки
- Команда /update — проверка и установка обновления с кнопкой подтверждения
- Команда /changelog — список изменений текущей установленной версии
- Уведомления админам о новой версии со списком изменений
- Режим AUTO_UPDATE (выключен по умолчанию) для полностью автоматической установки
- Файлы VERSION и CHANGELOG.md для версионирования


### Fixed
- Выбор прошедшего времени при админской записи
- Время окончания больше не может быть раньше начала при админской записи
- Ошибка «файл занят другим процессом» при повторном запуске бота
- Ошибка создания задачи автозапуска в Планировщике заданий
- Отказ в допуске участникам группы со статусом restricted

### Changed
- Ежемесячные отчёты по статистике (1-е число, 13:00)
- install_all.bat стал самодостаточным: сам создаёт все скрипты запуска и автозапуск

## [1.2.0] - 2026-10-15
### Added
- Админ-панель со статистикой и отчётами
- Антиспам и система банов
- Проверка пересечений времени записей
- Тестовый отчёт с выдуманными данными
- Кнопка админ-панели в главном меню для админов
- Ежемесячные отчёты по статистике (1-е число, 09:00)
- Запись за другого сотрудника через админ-панель

### Fixed
- Часовые пояса при получении событий календаря

### Changed
- Главное меню для админов: кнопка админ-панели вместо статуса прибора
