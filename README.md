# 🤖 HoriBot

**Telegram-бот для записи на прибор Horiba** с интеграцией Google Calendar, админ-панелью, статистикой использования и автообновлением.

Бот ведёт расписание прибора: сотрудники записываются на свободные слоты, все записи синхронизируются с общим Google-календарём, а рабочая группа получает уведомления о новых и отменённых записях.

---

## ✨ Возможности

- 📅 **Запись на прибор** — выбор даты через inline-календарь, времени через слоты или ручной тайм-пикер (шаг от ±1 мин до ±1 ч)
- 🔒 **Контроль пересечений** — бот не даст занять уже занятое время; касания интервалов разрешены
- 👥 **Авторизация по группе** — доступ только участникам рабочего чата; список обновляется автоматически при добавлении/удалении участников
- 🛡️ **Админ-панель** — статистика, отчёты, список банов, внесение записей за другого сотрудника (в том числе задним числом)
- 📊 **Статистика и отчёты** — команда `/usage`, красивые адаптивные HTML-отчёты, авторассылка админам 1-го числа в 13:00
- 🚫 **Антиспам и баны** — автоматическая защита от флуда сообщениями
- 🔄 **Самообновление** — проверка релизов GitHub при запуске и раз в сутки, установка по команде `/update` с changelog для админов
- 🪟 **Автозапуск с Windows** — единый скрипт `install_all.bat` настраивает окружение, зависимости, фоновый режим и автозагрузку

## 🚀 Быстрый старт

### 1. Установка

Достаточно одного файла — `install_all.bat`:

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте в рабочую папку.
2. Положите рядом `credentials.json` (ключ Google Service Account).
3. Запустите `install_all.bat` двойным кликом.

Скрипт автоматически:
- установит Python 3.14, если его нет (через winget);
- создаст виртуальное окружение и установит зависимости;
- создаст шаблон `.env`, если его нет;
- сгенерирует `start_bot.bat`, `start_bot_hidden.vbs`, `stop_bot.bat`;
- настроит автозапуск при входе в Windows (Планировщик заданий, с резервным вариантом через папку автозагрузки).

### 2. Конфигурация

Заполните файл `.env`:

| Переменная | Описание | Пример |
|---|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather | `123456789:ABC-DEF...` |
| `GROUP_CHAT_ID` | ID рабочего чата (начинается с `-100`) | `-1001234567890` |
| `CALENDAR_ID` | ID Google-календаря | `xxx@group.calendar.google.com` |
| `CALENDAR_LINK` | Ссылка для добавления календаря пользователям | `https://calendar.google.com/...` |
| `ADMIN_IDS` | Telegram-ID администраторов через запятую | `123456789,987654321` |
| `BOT_PROXY` | Прокси, если нужен (необязательно) | `socks5://user:pass@host:port` |
| `UPDATE_CHECK_ENABLED` | Проверка обновлений (`true`/`false`) | `true` |
| `AUTO_UPDATE` | Автоустановка без подтверждения (`true`/`false`) | `false` |

> Подробные пошаговые инструкции по подключению Google Calendar, правам бота в группе и обновлению — в HTML-инструкциях репозитория (`update_guide.html` и др.).

### 3. Запуск и управление

| Действие | Как |
|---|---|
| Запустить в фоне (без окна) | `start_bot_hidden.vbs` |
| Запустить с окном консоли (отладка) | `start_bot.bat` |
| Остановить бота | `stop_bot.bat` |
| Посмотреть логи | `bot_log.txt` |

Бот, запущенный через `start_bot.bat`, автоматически перезапускается при сбоях и потерях сети.

## 💬 Команды бота

**Пользователи:**

| Команда | Описание |
|---|---|
| `/start` | Приветствие и главное меню |
| `/book` | Записаться на прибор |
| `/my` | Мои записи (управление и удаление) |
| `/schedule` | Расписание на сегодня |
| `/usage` | Статистика за текущий месяц |
| `/cancel` | Отменить текущее действие |

**Администраторы (дополнительно):**

| Команда | Описание |
|---|---|
| `/update` | Проверить и установить обновление бота |
| `/changelog` | Изменения в текущей установленной версии |
| `/stats` | HTML-отчёт за прошлый месяц |
| `/refresh` | Принудительно обновить кэш участников группы |
| `/unban` | Разбанить пользователя |
| `/banlist` | Список забаненных |

├── config.py             # Конфигурация из .env
├── states.py             # FSM-состояния сценариев записи
├── auth_manager.py       # Авторизация, баны, антиспам, кэш участников
├── status_manager.py     # Статус прибора (вкл/выкл)
├── stats_manager.py      # Сбор и агрегация статистики использования
├── google_calendar.py    # Работа с Google Calendar API
├── update_checker.py     # Проверка и установка обновлений с GitHub
├── handlers/             # Роутеры: booking, status, admin, admin_panel,
│                         #          time_picker, stats, update
├── keyboards/            # Все inline-клавиатуры (слоты, календарь, меню)
├── middlewares/          # AuthMiddleware: доступ, бан, антиспам
├── reports/
│   └── stats_report.py   # Генератор HTML-отчётов (реальных и тестового)
├── install_all.bat       # ⭐ Единый скрипт установки и настройки автозапуска
├── setup.bat             # Установка окружения и зависимостей
├── VERSION               # Текущая версия (Semantic Versioning)
├── CHANGELOG.md          # История изменений (Keep a Changelog)
└── README.md             # Этот файл

Локальные данные (`.env`, `credentials.json`, `allowed_users.json`, `banned_users.json`, `status.json`, `bot_log.txt`, `venv/`, `reports/`) **не входят в репозиторий** и перечислены в `.gitignore`.

## 🔄 Обновления и changelog

Проект использует [Semantic Versioning](https://semver.org/lang/ru/) и формат [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

- История изменений ведётся в `CHANGELOG.md`; известные неисправленные баги — в секции `Known issues`.
- Релизы публикуются на странице **Releases**; описание релиза дублирует секцию changelog — именно его бот присылает админам.
- Бот проверяет новый релиз при запуске и раз в сутки, уведомляет админов списком изменений и устанавливает обновление по команде `/update` (или автоматически при `AUTO_UPDATE=true`).
- При обновлении локальные данные и настройки **не затрагиваются** (защищённый список путей).

**Текущая версия:** `1.3.1` (см. файл `VERSION`).

## 🛟 Troubleshooting

| Симптом | Решение |
|---|---|
| Бот не отвечает | Проверьте `bot_log.txt`; убедитесь, что бот запущен (`start_bot.bat` покажет окно с ошибками) |
| «У вас нет доступа к этому боту» | Пользователь должен состоять в рабочем чате; бот должен быть администратором чата |
| Ошибки Google Calendar | Проверьте `credentials.json` и права сервисного аккаунта на календарь («Вносить изменения в события») |
| Не создаётся задача автозапуска | Запустите `install_all.bat` от имени администратора или используйте резервный вариант (папка автозагрузки, `shell:startup`) |
| «Файл занят другим процессом» | Убедитесь, что не запущено два экземпляра бота; остановите старый через `stop_bot.bat` |
| Ошибка сети при запуске | Бот переподключается сам (экспоненциальная задержка); проверьте интернет/прокси |

## 🔐 Безопасность

- Секреты (`BOT_TOKEN`, ключи Google) хранятся **только** в `.env` и `credentials.json` вне репозитория.
- Персональные данные пользователей (`allowed_users.json`, `banned_users.json`) не публикуются.
- Автообновление по умолчанию работает в режиме уведомления (`AUTO_UPDATE=false`): установка только после подтверждения администратором.
